# Caddie Cat Support

Caddie Cat is a golf shot tracking app for iPhone.

## Common Help

### How do I start tracking shots?

Open the Round tab, start a round, then use Track Shot from the Distances screen. If GPS tracking is enabled, Caddie Cat measures the shot start and finish points.

### Can I enter distances manually?

Yes. In the Profile tab, set Shot Tracking to Manual, or edit the distance directly when recording a shot.

### Why does GPS distance show a confidence value?

Phone GPS accuracy varies by location, signal, trees, weather, and nearby buildings. Caddie Cat shows a confidence indicator so you know when a measured distance may need review.

### Can I review GPS distance?

Yes. Use the map button on the Record Shot form to audit the measured distance and move the start or finish point before saving.

### Where is my data stored?

Caddie Cat stores your golf data locally on your iPhone.
