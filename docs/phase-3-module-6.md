# Phase 3 Module 6 - Inactive Club Management

## Scope

- Split dashboard club state into active and inactive collections.
- Kept inactive clubs hidden from the main dashboard and target-yardage lookup.
- Added an inactive-clubs screen from the dashboard toolbar.
- Added swipe-to-deactivate on active clubs.
- Added restore and delete swipe actions on inactive clubs.

## Notes

- Active clubs remain the only clubs shown in target-yardage matching.
- Deactivating a club keeps it in local storage.
- Deleting from the inactive screen removes the club from local storage.
