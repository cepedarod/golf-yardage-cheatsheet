# Phase 3 Module 7 - Club Editing

## Scope

- Reused the native add-club form for editing existing clubs.
- Prefilled edit fields with the selected club details.
- Preserved club identity, active state, and created date when saving edits.
- Added edit swipe actions from active and inactive club lists.

## Notes

- Edited clubs remain in the same active or inactive collection after saving.
- The dashboard stays focused on quick distance reference, with edit controls tucked into swipe actions.
