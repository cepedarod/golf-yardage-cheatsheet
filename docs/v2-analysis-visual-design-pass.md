# V2 Analysis Visual Design Pass

## Scope

- Refined the club Analysis detail screen for faster at-a-glance reading.
- Added a tendency subtitle to Total Shots using the leading strike quality and direction for the selected category.
- Replaced the strike summary row with a stacked distribution bar, per-quality percentages, and shot counts.
- Replaced the direction list with a five-slice fan chart whose slices grow and intensify by hit percentage.
- Anchored the fan chart around the Straight slice so the center direction always stays centered.
- Added auto-dismiss behavior for shot distance entry after three digits, matching the target distance field.
- Kept recorded-shot history, edit, and delete behavior unchanged.

## Notes

- Strike and direction percentages still use all recorded shots for the selected club/category.
- Average distance behavior is unchanged: Pure shots with recorded distance only.
- The bespoke Thin, Pure, and Chunk icon set remains available for a later icon iteration pass.
